# Namu Voices

Голосовые пакеты для [Namu](https://github.com/SmaxsupeR/namu-app) — бесплатного тренажёра корейского языка. Пакет — это нейросетевая модель синтеза речи, которая работает **прямо на телефоне, без интернета**. Без пакета приложение говорит системным голосом Android.

> Голос синтезирован нейросетью. Модель: Supertonic 3 (Supertone Inc.), лицензия BigScience OpenRAIL-M.

## Пакеты

| Пакет | Размер | Голоса | Качество | Для каких телефонов |
|---|---|---|---|---|
| [`int8w`](packs/int8w) | 113 МБ | 10 (F1–F5, M1–M5) | как у оригинала: 29 из 30 тестовых фраз распознаются, отличие звука меньше разброса между запусками | быстрый режим — от 6 ГБ памяти, экономный — 3–4 ГБ |

Подробности измерений: [исследование TTS](https://github.com/SmaxsupeR/namu-app/blob/main/docs/tts-research.md). Цифры скорости там получены на сервере. Замеры на телефонах добавляются по мере проверки.

## Как устроено

```
index.json                  каталог пакетов: id, версия, размер, голоса
packs/<id>/manifest.json    все файлы пакета с размером и SHA-256
packs/<id>/onnx/            четыре ONNX-модели и словарь символов
packs/<id>/voice_styles/    голоса
packs/<id>/LICENSE          лицензия модели
packs/<id>/NOTICE.txt       что изменено и ограничения использования
```

Приложение читает каталог `index.json` и скачивает файлы пакета по ссылкам, привязанным к коммиту, в котором пакет опубликован (поле `ref`). Каждый файл проверяется по SHA-256 из манифеста:

```
https://raw.githubusercontent.com/SmaxsupeR/namu-voices/<ref>/packs/<id>/<путь из manifest.json>
```

Скачивание идёт по файлам, поэтому прерванную загрузку можно продолжить. Опубликованные файлы пакета не меняются: новая версия пакета — новая папка или новый коммит, а в каталоге обновляется `ref`. Так уже установленные пакеты остаются проверяемыми.
